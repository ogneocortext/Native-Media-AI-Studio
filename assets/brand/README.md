# Diamond Star Enterprises LLC — brand assets

The parent-company mark for this project. Native Media AI Studio is built and
owned by Diamond Star Enterprises LLC; these are the company's logo assets,
kept at repo level (product brand assets live in
`packages/frontend/public/brand/`).

## The mark

Direction A, "The Container" (design record: `design-brief-2026-11-25.md`).
A brilliant-cut diamond drawn in one uniform stroke, holding a single amber
four-pointed star at the center of its pavilion: the first child company.
The system rule is the point of the design — as child companies are added,
each earns a star inside the diamond, placed on the same internal grid, so
the parent mark fills as the family grows.

The keeper is exact vector geometry (code-drawn coordinates, perfect
bilateral symmetry, one stroke weight). Do not substitute AI-generated
redrawings; edit the SVG coordinates instead.
