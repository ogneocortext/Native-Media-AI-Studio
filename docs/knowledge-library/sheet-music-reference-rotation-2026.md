# Sheet-Music Reference Rotation — Where Professional Arrangements Come From

Research & Reference — the companion source list to
`external-book-sources-2026.md` (same policy: private study only;
what lands in this repo is distilled analysis in the project's own
words, never the source material). Owner direction, 2026-11-07:
keyword search is a short-term tactic; a curated rotation of durable
sources is the baseline strategy for professional-arrangement study.
First consumer: the chiptune work (T-MUS-06) and its measured
profiles (`pro-dungeon-measured-profile-2026.md`).

## The rotation

1. **MuseScore** (musescore.com) — full multi-part transcriptions,
   read as notation images in the viewer. Owner holds an account
   (created 2026-11-07 for this purpose). Downloads of copyrighted
   works are paywalled (Pro/Pro+ licensing); VIEWING is the route,
   and many scores view without sign-in. Best for: complete
   arrangements with all voices visible.
2. **NinSheetMusic** (ninsheetmusic.org) — curated video-game piano
   arrangements; free PDF/MIDI/MUS per piece, editor-gated quality.
   Best for: arrangement craft in our exact genre, machine-readable
   MIDI without an account.
3. **Ichigo's Sheet Music** (ichigos.com) — game and anime
   transcriptions by NAMED transcribers (quality is attributable);
   PDF/MUS/MIDI per piece, MIDI on many. Best for: second opinions
   on a title NinSheetMusic lacks.
4. **VGMusic** (vgmusic.com) — the deep archive: 30,000+
   human-sequenced MIDIs across ~47 platforms, staff-reviewed since
   1996, rips rejected. Variance is the price of depth; every file
   credits its sequencer. Best for: scale — many versions of a
   track to measure against each other.
5. **Hooktheory TheoryTab** (hooktheory.com) — the analysis layer:
   40,000+ chord-and-melody analyses, free to explore, each with
   computed complexity metrics; the Trends tool gives progression
   probabilities across the corpus. Best for: baseline numbers
   (what progressions actually do) rather than single examples.
   Popular-music skew; thin on game scores.
6. **IMSLP** (imslp.org) — public-domain scores (PDF, some MIDI).
   The permanence anchor: counterpoint, voice-leading, and form
   that stay relevant indefinitely. Best for: fundamentals when a
   game source and a classical source should agree.

## The protocol

- **Rotate per study, not per search**: each new genre or craft
  question starts at the rotation, one source per pass.
- **Two-source agreement rule**: a measured statistic earns
  influence over the generator or the lint only when two rotation
  sources agree on it. One score is a reference point (the dungeon
  profile is labelled exactly that); two make a baseline.
- **Credit discipline**: transcriptions are arrangements by people;
  record the transcriber/sequencer name with every measurement, the
  way the dungeon profile credits its arranger.
- **Private study only**: scores are viewed or downloaded for
  measurement; nothing from a source is committed, redistributed,
  or reproduced — statistics and rules in our words are the only
  artifacts (per `external-book-sources-2026.md`).
- **Maintenance**: re-verify each source's access model yearly
  (paywalls move — MuseScore's download policy changed in 2020);
  a source that paywalls viewing drops to the bottom of the
  rotation, it does not get bypassed.
