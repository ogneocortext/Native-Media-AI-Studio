# GPU Music Video Pipeline Guide

> **Last Updated:** August 2026 • **Tested:** `GTX 1070 Ti 8GB VRAM, CUDA 12.4, PyTorch 2.5.1+cu124, FFmpeg 8.1.1`

## Architecture

```
Audio File (E:\HappyShrimp\*.mp3)
  → POST /api/audio/analyze → librosa (tempo, beat_times, energy_curve) → 8 sections
  → build_full_scene({beat_times}) → bpy scripts → Blender MCP (port 9876)
  → Hunyuan3D-2mini / Wan 2.2 5B → Blender import → EEVEE Next / Cycles CUDA → frames
  → FFmpeg testsrc+geq filter + audio → MP4 (Media Library)
```

## Components

### 1. Audio Analysis — Real (`app/api/audio.py:100` + `app/services/audio_analyzer.py:133`)

No CUDA `torch.stft` in current path — `librosa` runs on CPU (2-5s for 3 min track), results are energy-aware sections.

```python
from app.services.audio_analyzer import AudioAnalyzer

analyzer = AudioAnalyzer(hop_length=512)
result = analyzer.analyze_file("output/audio/85a406ef_Take the Crown.mp3", job_id="85a406ef")
# result.beats.tempo_bpm, result.beats.beat_times, result.waveform.rms_energy, result.waveform.amplitude_envelope
# API wraps as: POST /api/audio/analyze (multipart file) → {tempo_bpm, duration_seconds, beat_times[800], energy_curve[100], sections[8]}
```

*Backend `POST /api/audio/analyze` does this and saves `output/audio_analysis/{id}_analysis.json`.*

**No `from app.services.cuda import cuda_audio` import** — that module exists as `app/services/cuda/processor.py` for visualization FFT only; audio analysis is `librosa`-based.

### 2. 3D Model Generation (`app/services/gen3d/service.py` + `GET /api/health/3d/*`)

Via `POST /api/health/3d/generate`:

```bash
curl -X POST http://localhost:8000/api/health/3d/generate \
  -H "Content-Type: application/json" \
  -d '{"prompt": "a futuristic robot, chrome metallic", "steps": 15, "seed": 42}'
# → {"success": true, "model_path": "output/generated_3d/...glb"}
```

Direct Python:

```python
from app.services.gen3d.service import gen3d_service

# Text-to-3D (shape only, 8GB-safe)
res = await gen3d_service.generate(prompt="a neon microphone, cyberpunk style", steps=15)
# or legacy sync wrapper:
# result = gen3d_service.generate_from_text("a futuristic robot", steps=15)
```

Model: `ComfyUI/models/diffusion_models/hunyuan3d-2mini` (~2.5GB). For `Wan 2.2 5B` video at `480p` fits 8GB (see `comfyui-workflows.md`).

### 3. Blender Scene Builder (`app/services/blender/builder.py`)

Generates **bpy scripts**, not direct Blender calls — scripts are executed via MCP `blender_execute_blender_code`.

```python
from app.services.blender.builder import BlenderSceneBuilder

builder = BlenderSceneBuilder(render_engine='CYCLES', resolution=(1920, 1080), fps=24)
scripts: list[str] = builder.build_full_scene({
    'stage': 'abstract',  # concert | abstract | nature | urban | space
    'beat_times': [20.3, 20.9, 21.5],
    'beat_intensity': 0.8,
})
# for s in scripts: blender_execute_blender_code(code=s)
```

### 4. Lyrics Sync (`app/services/blender/lyrics_sync.py`)

Optional, for WhisperX timed lyrics:

from app.services.blender.lyrics_sync import LyricsSyncMapper

mapper = LyricsSyncMapper(fps=24)

### 5. Blender MCP Integration

**Install (current):**

```powershell
uvx blender-mcp install-addon
# Then in Blender 5.2: Edit → Preferences → Add-ons → enable "Blender MCP" → N-panel → Start MCP Server
```

Server: `localhost:9876` (MCP) — *not* ComfyUI `8188`.

**Tools (via `unity_command` style `blender_*`):**

- `blender_execute_blender_code(code: "import bpy; ...")`
- `blender_get_scene_info()` / `blender_get_object_info(object_name="Cube")`
- `blender_get_viewport_screenshot()`

*PolyHaven/Sketchfab downloads via same MCP when needed.*

## Workflow: Happyshrimp Track → 3D Video (Real)

1. **Analyze:** `POST /api/audio/analyze` with `E:\Generated by HappyShrimp(beta)\Take the Crown.mp3` → `8 sections`, `beat_times[0]=20.329s` (matches doc `20.36s`).
2. **3D props (optional):** `POST /api/health/3d/generate` or `Wan 2.2` via ComfyUI.
3. **Build stage:** `builder.build_full_scene({stage:'abstract', beat_times})` → MCP execute.
4. **Animate:** Keyframe on `beat_times` (see `MINDFUL_LAYERING_2026.md` for `<800ms` budget).
5. **Render:** `Cycles 128 samples ~30s/frame` or `EEVEE Next 64 TAA ~2s/frame` — see Performance table.
6. **Encode:** `POST /api/video/generate-section` with `audio_path` from step 1 → `MUSIC_VIDEO` job → `FFmpeg geq=...:cb=...:cr=...,format=yuv420p` (fixed `handler.py:213` colon bug) → `output/video/*.mp4`.

## Troubleshooting (only pipeline-specific — general `MUSIC_VIDEO_GUIDE.md`/`FILE_MANAGEMENT.md` not repeated)

| Issue | Fix |
|---|---|
| `503 librosa not installed` on `/audio/analyze` | `venv\Scripts\python -m pip install librosa soundfile` → restart backend (`Stop-Process :8000` → `venv\Scripts\python -m app.main`) |
| `FFmpeg failed: No option name near` | Was `geq: lum,cb,cr` comma bug — fixed `handler.py:213`; pull latest |
| `Blender MCP tools not appearing` | `uvx blender-mcp install-addon` → enable → N-panel Start; ensure no other process on `9876` |
| `VRAM full during 3D` | Reduce `steps 30→15`, close ComfyUI/Blender, `GET /api/health/gpu` check |
| `3D model won't generate` | Check `ComfyUI/models/diffusion_models/hunyuan3d-2mini` exists |
| `cover.jpg` not shown for audio | Click `Media Library → Refresh` — extraction runs on scan `outputs.py:93` |
