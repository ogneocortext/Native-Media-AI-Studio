# Documentation

This directory contains project documentation, knowledge base articles, and setup guides.

## Directory Map

| Directory / File | Purpose |
|------------------|---------|
| `guides/` | Production guides: GPU pipeline, visualizer debugging, music video workflow, setup summaries |
| `setup/` | Environment setup docs: Conda, Python envs, model setup, video setup |
| `knowledge-library/` | Research and reference articles (3D gen, Ollama, Blender MCP, Remotion, visualization, benchmarks) |
| `knowledge/` | Kilo-specific knowledge fragments |
| `api/` | API documentation |
| `api-database/` | Database schema and migrations |
| `architecture/` | Architecture decision records |
| `comfyui-workflows/` | ComfyUI workflow reference |
| `notes/` | Development notes |
| `scratch/` | Ad-hoc scratch outputs, diagnostics, one-off research — **not authoritative** |
| `screenshots/` | Documentation screenshots |
| `ux-audit/` | UX audit findings |
| `visual-storytelling/` | Visual storytelling references |
| `archive/` | Archived or superseded docs |

## Key Files

- `Guidelines.md` — Living specification and implementation guide (source of truth for project decisions)
- `AGENTS.md` — Agent-specific instructions and project rules
- `ENHANCEMENT_RECOMMENDATIONS.md` — Proposed improvements
- `SYSTEM_REQUIREMENTS.md` — Hardware and software requirements
- `TESTING_WORKFLOWS.md` — Testing instructions
