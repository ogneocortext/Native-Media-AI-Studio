# Frontend Features

This directory groups the React app by **feature domain** so agents can jump straight to the relevant code during development sessions.

## Feature Modules

| Directory | Purpose |
|-----------|---------|
| `ai-tools/` | AI-assisted tooling panels |
| `art-direction/` | Art direction and style controls |
| `audio-analysis/` | Audio analysis UI and waveform displays |
| `dashboard/` | Main dashboard shell and health indicators |
| `docs/` | In-app documentation and help panels |
| `generate3d/` | 3D generation workflows and previews |
| `gpu/` | GPU diagnostics and profiling UI |
| `health/` | Backend/adapter health status widgets |
| `hyperframes/` | HyperFrames composition previews |
| `image-generation/` | Image generation queue and gallery |
| `kinetic-typography/` | Kinetic typography / lyric animations |
| `log-analytics/` | Log viewing and analytics dashboards |
| `logs/` | Real-time log streaming UI |
| `media-library/` | Media library browser and asset picker |
| `music-prompts/` | Music prompt presets and management |
| `music-video/` | Music video creation wizard |
| `ollama-chat/` | Ollama chat integration UI |
| `preview/` | Composition preview and playback |
| `queue/` | Job queue UI and progress tracking |
| `settings/` | App settings and configuration panels |
| `storyboards/` | Storyboard editing and timeline |
| `three-js-studio/` | Three.js 3D studio integration |
| `video-generation/` | Video generation workflows |
| `visualizer/` | Canvas2D / shader visualizer (bars, waveform, radial) |

## Cross-Cutting Paths

- Shared components: `../components/`
- Shared hooks: `../hooks/`
- Shared types/utils: `../shared/`, `../utils/`
- API services: `../services/`
- Global state: `../state/`
- Styles: `../styles/`
- Pages: `../pages/`
